Mirage Console

Snowsight for agent data access

Open a run, scrub the bytes, answer "model mistake or data mistake?" in one glance. A workspace-scoped, read-first console: one persistent shell, the center swaps exactly one object — a Run or a Data object — and a shared selection keeps both worlds cross-lit. Borrowed deliberately: Snowflake's profile + auto-profiling, Databricks' lineage, Redux's time-travel.

Snowflake → Profile + Data view

Run history as first-class objects · a query-profile over the real VfsOp spine (most-expensive ops) · a Snowsight data grid with per-column profiling.

Databricks → Lineage

"Touched by N runs" on any data path — the data ↔ trace bridge, both directions, from the real mount_prefix+path join.

Redux → Time-Travel

The action stream as a recording: scrub a cursor, stateAt(idx) fold, exact per-action diff, skip-what-if, export a replayable session.
